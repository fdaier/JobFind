# JobFind 邮件进度逐条审批实施计划

1. 先补单元测试：信号证据、岗位匹配、状态前进／冲突／待核对、重复邮件和本地备份幂等。
2. 扩展扫描观察字段并从既有批次恢复候选；服务端新增审批决定表及认证 API，迁移 Supabase，连接／断开时安全清理决定。
3. 增加只在用户确认时触发的本地岗位更新动作和独立备份，时间线记录邮件事件 ID，失败回执可重试。
4. 构建状态收件箱的建议／待核对两栏、可恢复队列和单条审批弹窗；匹配不足时须用户手动选岗位与阶段。
5. 运行测试、类型检查、lint、构建及浏览器回归；用真实 163 样本线上只读验证队列，不代替用户实际审批其岗位。确认 Vercel 项目与域名后发布，更新现状及部署 SOP 并提交。
