# JobFind 公司池实施计划

1. 扩展 `Job` 与 store，加入可选 `companyId`、公司池持久化和受控别名迁移。
2. 建立用户提供名单的本地种子数据，以及主梯队、城市、别名和投递状态的派生工具。
3. 在申请看板控制条加入公司池入口，实现地区／梯队浏览、状态颜色、悬停上浮与已投岗位跳转。
4. 实现名单管理模式及岗位详情中的名单公司选择器。
5. 覆盖匹配、迁移、分组、状态与关键交互的测试，运行类型检查、lint、Vitest 与生产构建。
