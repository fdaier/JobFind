# JobFind 看板流程、备注与岗位编辑实施计划

**设计：** `docs/superpowers/specs/2026-09-14-jobfind-board-workflow-and-editing-design.md`

1. 扩展领域类型与集中阶段标签/顺序工具；更新演示数据、规则引擎、统计与所有旧阶段引用。
2. 在存储层实现幂等的旧阶段迁移、原始 JSON 备份和非破坏性校验；编写迁移测试。
3. 扩展 store 的受限编辑 API，保证材料双向绑定、阶段历史、时间线和复盘编辑均持久化。
4. 更新看板：十阶段、轻量三信号卡片、备注展示；更新导入流程与详情阶段控件。
5. 给详情的基本信息、材料、时间线、面试复盘加入页级编辑态；Agent 面板维持只读。
6. 将术语抽取改为分段、去宽泛词的可解释规则，并更新预览/详情文案。
7. 增补单元和组件测试；运行测试、类型检查、lint、构建与浏览器回归。确认 Vercel 项目后部署，检查 `https://jobfind.fdaier.xyz`。
