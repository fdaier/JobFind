# JobFind 日期时间输入与预览滚动设计

> 状态：已批准，实施中  
> 日期：2026-09-15

## 目标

让所有用户填写的日期使用同一套年、月、日分栏输入与日历选择；日期时间增加独立时分输入。移除测评链接示例占位，并使 JD 整理预览在普通窗口中可滚动到保存操作。

## 范围

- 新增复用“日期 + 时分”控件，并用于导入 JD、预览和岗位详情的测评截止、笔试、面试时间。
- 现有网申截止时间继续使用仅日期控件。
- 测评链接输入框无 placeholder。
- JD 导入弹窗最大高度受动态视口限制；标题保留，工作内容拥有独立纵向滚动。

## 数据保护

只替换呈现和输入方式。既有 ISO 时间、链接和其余 localStorage 数据原样保留；日期时间按本地时区回显和保存。

## 验收

1. 日期不显示浏览器默认 `yyyy/mm/dd` 样式，仍可用日历选择。
2. 测评、笔试和面试时间可回显、编辑、保存到 ISO 时间。
3. 测评链接框不含示例 placeholder。
4. 在非全屏桌面窗口中，预览页可正常滚动到“保存到看板”。
5. 测试、类型检查、lint、构建和浏览器回归通过。
