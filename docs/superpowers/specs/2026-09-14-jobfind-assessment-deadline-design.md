# JobFind 测评截止时间设计

> 状态：已批准，实施中  
> 日期：2026-09-14

## 目标

让收到测评链接的既有或新建岗位可记录精确截止时间与可选链接；在看板卡片显示最近关键时间，并由现有确定性 Agent 在应用打开时提示临期或逾期测评。

## 范围

- 岗位新增 `assessmentDeadline` 与 `assessmentLink` 两个可选字段，分别保存 ISO 时间与用户原样填写的链接。
- 详情“基本信息”编辑态新增“关键时间”分组：保留网申截止日期输入，并提供测评截止、笔试时间、面试时间和可选测评链接的编辑入口。
- JD 导入的填写页及预览页同样可录入测评截止时间与链接。
- 看板卡片继续只显示一个最近的未来关键时间；测评截止显示为“测评截止”。
- 当岗位阶段为“测评”时，Agent 增加 `assessment_deadline` 风险及 `take_test` 今日任务：72 小时内提示、高于 24 小时为高优先级，24 小时内或逾期为紧急。

## 不做

- 不自动访问、解析或提交测评链接。
- 不做应用关闭后的浏览器通知、手机推送、短信或邮件；本期提醒只在打开 JobFind 时出现于卡片、作战台和 Agent 排序。
- 不改动既有岗位的公司、岗位、JD、材料、时间线、复盘、备注或原有日期。

## 数据安全

读取旧 localStorage 时仅为缺失的新增字段补 `null`，通过既有安全迁移和持久化逻辑保存。不会重置演示数据，也不会覆盖已保存内容；既有 V3 原始备份不会被覆写。

## 验收

1. 既有岗位编辑、刷新后仍保留全部原有数据，且可新增保存测评时间和链接。
2. 新建岗位的输入、预览和最终保存使用同一份测评时间和链接。
3. 看板在测评截止时间为最近未来节点时显示“测评截止”。
4. 测评阶段按 72/24 小时和逾期阈值生成正确风险、今日任务和优先级。
5. 类型检查、单测、lint、生产构建以及本地和生产浏览器回归通过。
